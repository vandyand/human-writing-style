# Corrections (optional)

Copy this file to `corrections.md` in the same folder. The agent reads `corrections.md` when it exists and treats every entry as more authoritative than `style-guide.md`. Keep it private. Add an entry whenever you edit a draft and the change says something about how you actually write.

Good entries are short, specific, and show the before and after. Newest first is fine.

## Format

```
### [Short name for the pattern]
- Draft said: "[what the agent wrote]"
- I changed it to: "[what you wrote instead]"
- Why: [one line, if it isn't obvious]
- Applies to: [everything / Slack / emails to clients / one recipient]
```

## Example entry

### Plain verb, not a flourish
- Draft said: "This unlocks real leverage for the team."
- I changed it to: "This should save the team some time."
- Why: I don't talk in abstractions like that.
- Applies to: everything

## Always / never

Standing rules that don't need a before and after.

- Always: [e.g. sign off with my first name only in emails]
- Never: [e.g. use exclamation points with clients I haven't met]
